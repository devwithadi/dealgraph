DealGraph · high-level architecture

Evidence enters; auditable decisions leave

One CLI command coordinates public startup sourcing, bounded semantic screening, finalist diligence, deterministic scoring, and cited memo generation. The pipeline owns orchestration and failure isolation; immutable domain contracts carry evidence between stages.

Orchestration

One bounded, reviewable run

  • app/cli/main.py is the only supported interface and top-level error boundary.
  • app/pipeline/service.py validates configuration, sequences stages, and emits progress.
  • Per-company failure isolation preserves successful finalists and records safe gaps.

Evidence boundary

Facts carry provenance

  • Immutable Pydantic contracts represent candidates, evidence, screening decisions, analyses, and summaries.
  • Only enabled public sources enter the corpus; unknown facts remain unknown.
  • Every narrative citation must resolve to collected evidence.

Decision boundary

The model cannot choose the score

  • Models screen and draft cited narrative fields.
  • Python validates five dimensions, recomputes the weighted score, confidence, and recommendation.
  • PDF and JSON artifacts preserve the reviewer-visible trail.
